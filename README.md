# Odoo Apps by Muhammad Ramzan

Odoo modules published on the [Odoo Apps Store](https://apps.odoo.com).
Each branch targets one Odoo version (`17.0`, `18.0`, `19.0`).

| Module | Description |
|---|---|
| [mrz_deletion_audit](mrz_deletion_audit) | Deletion Audit Trail: who deleted which record, when, from where, and a full snapshot of what it contained, including child records removed with it. |
